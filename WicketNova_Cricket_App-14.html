🎬 YouTube Live mein score dikhane ke steps

  1. WicketNova mein match create karke scoring start karein.
  2. Compact Score Bar kholein; nayi transparent window khulegi.
  3. Computer par OBS Studio → Sources → + → Window Capture choose karke “WicketNovaStreamOverlay” window select karein.
  4. Score bar ko video ke neeche drag karein, phir OBS se YouTube par stream start karein.

Recommended: Window Capture use karein, kyunki OBS Browser Source alag storage mein chal sakta hai aur live match data read na kar paaye. YouTube description ke neeche dynamic score nahi lagta; score video ke andar overlay hota hai.
